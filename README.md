# 🌾 Smart Agriculture Advisory Platform

An AI-driven platform that provides real-time, personalized guidance to farmers 
to optimize crop health, resource usage, and productivity.

## Modules
| Module | Status |
|---|---|
| Yield Prediction | 🔄 In Progress  |
| Crop Disease Detection | 📅 Planned |
| Fertilizer Recommendation | 🔄 In Progress |
| Weather Advisory | 📅 Planned |
| Backend API | 📅 Planned |
| Frontend | 📅 In Progress|

## Tech Stack
- **ML:** XGBoost, CNN, Scikit-learn, SHAP
- **Backend:** FastAPI 
- **Frontend:** Planned 

## Project Structure
```
smart-agriculture-platform/
├── yield-prediction/    # Yield forecasting — XGBoost + SHAP
├── disease-detection/   # CNN crop disease classifier
├── fertilizer-recommend/ # Fertilizer recommendation model
├── weather-advisory/    # Weather-based advisory engine

```
